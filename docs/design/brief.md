# Cover design brief

Purpose: introduce Technical Visual Explainer to researchers, technical writers and developers visiting the repository. The visual demonstrates one coherent overview and its connected detail. AutoResearchAgent is a separate development example, not the cover's subject.

Three assets: English README cover, Traditional Chinese README cover, English GitHub Social preview. All have a white editorial composition, approximately 40% type and 60% diagram. README aspect ratio is 2:1; Social preview export is 1280 x 640 and below 1 MB.

| Element | Work / meaning | Encoding |
|---|---|---|
| Map | Organize parts and relationships | Purple filled nodes glyph; method |
| Draw | Produce the figure with the host's image tool | Blue filled drawing glyph; tool |
| Check | Inspect the figure | Green filled inspection glyph; check |
| Labels / Links | Two inspection aspects inside Check | Green sub-elements; no sequential arrow |
| Revise | Return from checking to drawing | Orange labeled return arrow |
| Focus outline | Identify the part being expanded | Navy boundary, independent of role/status |

| Connection | Meaning |
|---|---|
| Map -> Draw -> Check | Main workflow; solid navy arrowheads |
| Check -> Draw | Correction; orange arrow routed above the main flow |
| Check -- Labels / Links | Detail expansion; neutral dashed leader with no arrowhead |

The cover is a compact method illustration, not a complete execution contract. It does not claim every defect requires only drawing changes, nor that checking establishes factual correctness or audience understanding. Full reasoning and return choices remain in the skill.

English title: Technical Visual Explainer. README subtitle: Clear diagrams, from overview to detail. Chinese title: 技術圖解, with the English name. Chinese subtitle: 把複雜關係畫清楚，從總覽一路展開。 Social subtitle: Clear diagrams. Connected details.

Color meanings: purple #7652B5 Method, blue #2876C7 Tool, green #298550 Check, orange #D86B28 Revision. Navy #12233F for text, focus and normal connections. The legend stays inside each independently used cover. Flat filled functional icons are required; role colors do not imply measured values. No decorative gradients, glows, paper texture, robots or 3D effects.

Create and inspect the English master, derive the Chinese version with deliberate line breaks, then derive a larger-type Social preview. Complete covers use built-in imagegen. Resizing and encoding only may use ordinary image utilities; original generated files and prompts are retained. No specific image model is claimed unless the tool exposes it.

Acceptance: inspect arrow endpoints and magnification meaning, icon fill/category consistency, all exact text, Chinese glyphs, 900px README display, and 640px/320px Social thumbnails. At 320px the name and primary composition must remain recognizable; small instructional labels are assessed at the larger reading sizes. Actual audience comprehension remains unmeasured.
